# Workspace Customization Rules - DinePosAi

All development tasks in this workspace MUST follow the 7-Phase AI Development Workflow:

1. **UNDERSTAND**: Read AGENTS.md, relevant docs/, inspect existing code & patterns before coding.
2. **PLAN**: Provide a practical plan covering changes, files, reusable code, DB/API updates, risks, and testing approach. Ask if ambiguous.
3. **IMPLEMENT**: Make smallest safe change, follow patterns, reuse code, preserve existing functionality, enforce security.
4. **TEST**: Run pnpm test, pnpm build, verify affected functionality & regressions.
5. **REVIEW**: Verify compliance, architecture adherence, simplicity, error handling, and security.
6. **DOCUMENT**: Update docs/ if architecture, DB schema, API behavior, auth, or conventions changed.
7. **FINAL REPORT**: Output structured summary (Changed, Why, Tests, Documentation, Risks, Git).
