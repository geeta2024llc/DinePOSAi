1. AUTH FLOW (LOGIN / SIGNUP)

1.1 Signup Page
UI Elements
Business Name
Email
Password
Confirm Password
Country selector
“Start Free Trial” button
Button: Start Free Trial
On Click:
Validate inputs
Create tenant
Create admin user
Start 14-day trial
Redirect → Onboarding Flow

Success State
“Account created successfully”
Redirect to onboarding

Error States
Email already exists → show “Account already exists”
Weak password → show validation error
Network error → “Try again”

1.2 Signin Page
Inputs:
Email
Password
Button: Sign In
On Click:
Validate credentials
Check subscription status
Check device limit

Success Flow:
Redirect based on role:
Admin → Manager Dashboard
Cashier → POS
Kitchen → KDS

Error States:
Invalid credentials → “Incorrect email/password”
Account suspended → “Contact admin”
Device limit reached → force logout old device

1.3 Forgot Password
Flow:
Enter email
Send reset link
States:
Success → “Reset link sent”
Error → email not found
